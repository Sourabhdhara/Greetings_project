## 🌟 Introduction
*A beautiful Python tkinter GUI and web application that shows animated greetings that change through morning, afternoon, evening, and night.*

Welcome to the **Animated Time Greeting Application**! This project delivers a beautiful, immersive greeting experience that smoothly transitions through four distinct phases of the day: Morning, Afternoon, Evening, and Night. 
[![Python](https://img.shields.io/badge/Python-3.6+-3776ab?style=for-the-badge&logo=python&logoColor=white)](https://python.org)

Available as both a **Python Desktop App** and an **Interactive Web App**, it features rich canvas animations, pulsating typography, and mesmerizing background gradients that change seamlessly as time passes.

## ✨ Features

- **🕰️ Real-Time Adaptation**: The application automatically detects your local time and switches its theme accordingly.
- **🎨 Four Unique Visual Themes**: Hand-crafted gradients, colors, and animations for Morning, Afternoon, Evening, and Night.
- **💫 Canvas Animations**: Enjoy smooth, performant HTML5 canvas animations featuring twinkling stars, moving clouds, and floating particles.
- **🖥️ Cross-Platform Accessibility**: Run it natively on Windows using the provided executables, or open the web version in any modern browser.
- **📱 Responsive Design**: The web interface beautifully scales to look perfect on desktops, tablets, and mobile devices.

## 🧭 App Versions

The app continuously breathes life into your screen, adapting its visuals based on the current hour:
This repository includes two desktop versions of the app:

| Time of Day | Visual Elements & Atmosphere | Time Range |
| :--- | :--- | :---: |
| 🌅 **Morning** | **Bright Sunrise:** Watch the animated sun emit rotating rays against a beautiful morning gradient. | `12 AM - 12 PM` |
| ☀️ **Afternoon** | **Golden Sunshine:** Experience a bright, pulsing sun accompanied by gently drifting clouds. | `12 PM - 5 PM` |
| 🌆 **Evening** | **Purple Sunset:** Relax with a setting sun and floating, magical particles over a deep purple horizon. | `5 PM - 8 PM` |
| 🌙 **Night** | **Starry Night:** Gaze at twinkling stars and a glowing, atmospheric moon set against a dark blue sky. | `8 PM - 12 AM` |

## �🚀 How to Use

Experience the magic through your preferred medium:
### 🐍 Python Application
python Greetings_project.py

### 🌐 The Web Experience
The easiest way to see the animations in action!
1. Clone the repository or download the files.
2. Simply double-click the `index.html` file to open it in any modern web browser.
3. *Alternatively, visit the live demo: [Live Web Version](https://sourabhdhara.github.io/Greetings_project)*
### 💻 Windows Executable

### 🐍 Python Desktop App
To run the source code directly:
```bash
# Navigate to the version you want to run
cd "Greetings_project _v2.0"
### 🌐 Web Application
Open the `index.html` file in a modern browser.

# Run the Python script
python "Greetings_project _v2.0.py"
```
---

### 💻 Windows Executable (.exe)
Don't want to install Python? No problem!
1. Open the `Greetings_project _v2.0` directory.
2. Double-click the `Greetings_project-v2.0.exe` file.
3. Enjoy the standalone desktop application!
